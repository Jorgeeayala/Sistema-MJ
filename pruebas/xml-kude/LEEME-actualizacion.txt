ACTUALIZACIÓN — DÚO AUTOMÁTICO + IMPRIMIR TODO (pestaña XML / KuDE)
=====================================================================
Requisito previo: tener aplicada la integración anterior
(Sistema-MJ-parser-xml.zip).

QUÉ AGREGA
----------
- Botón «Imprimir todo (N hojas)» cuando hay más de un documento:
  empaqueta automáticamente las facturas cortas de a 2 por hoja
  (las más aptas entre sí, algoritmo de tu parser) y las largas en
  hoja completa, en papel Oficio como tu app original.
- Resumen del empaquetado en el panel de documentos (cuántas hojas,
  cuánto papel se ahorra).
- Sin ajustes manuales y sin botón PDF: para PDF se usa
  «Guardar como PDF» del diálogo de impresión.

CÓMO APLICARLO (Windows, CMD)
-----------------------------
1) Descomprimí este zip.
2) Copiá la carpeta src sobre tu Sistema-MJ, aceptando «Reemplazar»
   (se reemplazan 2 archivos y se agregan 3, todo dentro de src\xml).
3) No hay dependencias nuevas: no hace falta npm install si ya
   instalaste la integración anterior. Solo reiniciá el servidor:

     npm run dev

PRUEBA SUGERIDA
---------------
Cargá 3 o más XML: el panel muestra el resumen del empaquetado y el
botón pasa a decir «Imprimir todo (N hojas)». Al imprimir, la vista
previa debe mostrar hojas Oficio con 2 facturas y la línea de corte
al medio; las facturas de más de 5 ítems salen en hoja completa.
